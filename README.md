# tamago2 — お世話して、ひと休み。

初期の携帯育成玩具の操作感を参考にした、オリジナルキャラ「まめ」の育成Web試作。tamagoリポジトリとは別物です。

## 遊ぶ

公開先: https://tamago2.itisnowornever271.workers.dev/

検証用: https://tamago2.itisnowornever271.workers.dev/?dev=1

公開済みバージョンは画面下部と `/version.json` で確認できます。リポジトリ更新とCloudflare反映は同じ意味ではありません。mainのCIで配信ファイルまで照合します。

## 操作

アイコン直接タップ、または A=選択 / B=決定 / C=戻る。キーボードのA/B/Cでも操作できます。

- ごはん: ごはん・おやつ。食べる演出、満腹・食べすぎ・連打防止。
- トイレ: うんちを流す。掃除の演出。
- くすり: 病気を治療。健康な時は不要。汚れている場合は掃除も必要。
- でんき: 消灯/睡眠、点灯/起床。眠っている間は他のお世話不可。
- あそぶ: 左右を選ぶ1回のミニゲーム。連続プレイにクールダウン。
- ようす: おなか・ごきげん・けんこう・しつけの4段階ハートと記録。
- しつけ: 必要なときだけ反応。空腹・病気のときは先にケア。
- おやすみ: 30分タイマー。終了後の自己申告で成長。

卵→赤ちゃん→こども→わかもの→おとな。使用過多で退化、汚れや低健康で病気、健康0でお別れ。新しい世代へ再開できます。キャラの顔は明るい顔面に暗い目。歩く足、瞬き、耳、しっぽは別パーツで動かし、画面全体の再描画で動きをリセットしません。

## 計測の限界とゲームルール

Webは端末全体のスクリーンタイムを読みません。このページの実際の表示時間と、休息の自己申告だけを使います。非表示=スマホ未使用とは見なしません。30分経過しただけで休息成功にはせず、本人の確認を必須にしています。タブの非表示・復帰・再読み込みでタイマーを保持します。

最初の表示10分はケア用の猶予。進化の試作閾値は30/90/180。休息30分で成長+30、猶予後のページ表示1分で成長-0.8。値は調整用で、健康・行動改善の科学的効果を意味しません。

未訪問だけでは死にません。非表示時の生活更新は最大8時間まで、健康への悪化は適用しません。通常モードと検証モードは別保存。v1/v2からは値を検証して引継ぎ、元キーは削除しません。localStorageが利用できないと警告します。

## 開発

Node.js 22+。`npm install` → `npm run build` → `npm run dev`。

`npm run test:unit` / `npm test`。ChromiumとWebKitの実操作、見た目、保存、退化、休息確認、死亡・再スタートをテスト。

`npx wrangler deploy` は build を実行して dist の明示許可した8ファイルだけ配信します。APIキー・ユーザー情報・テスト・依存パッケージは公開しません。課金サービスや外部生成APIは使用しません。
