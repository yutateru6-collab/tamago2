# ひといき（仮称） — tamago2

あなたにも、この子にも、自分の時間。既存のドット絵・LCD・3ボタンを残した、デジタルデトックスのWeb試作。

公開: https://tamago2.itisnowornever271.workers.dev/

検証モード: https://tamago2.itisnowornever271.workers.dev/?dev=1

## 今回の体験

- 卵型の外枠を撤去。表示領域いっぱいのLCDと、A/B/Cの操作帯。端末のセーフエリアに対応。
- 表示名は仮に「ひといき」。リポジトリ名とWorker名はtamago2のまま。
- ごはん・トイレ・くすり・でんき・あそぶ・ようすは維持。
- 「しつけ」を「やくそく」に変更。15/30/60分と、休息・読書・集中・食事の意図を選ぶ。
- 主操作は「スマホを置く」。世話だけを繰り返しても進化しない。
- 確認済み休息の後に独自の小さな物語。窓、葉っぱ、カップ、植物、絵本が少しずつ増える。
- 3回目の確認済み休息から軽い食事、4回目から片付けも、自立の表現としてゲーム状態に反映。
- 暮らしの記録を30件まで保存。連続ログイン義務・通知・広告・課金による救済なし。
- Cはタイマーを中断せず戻るだけ。中止は明示ボタンで行う。

## 誠実な計測と保存

WebからiPhone全体の利用時間・他アプリの行動は分からない。計測はこの画面の観測できた表示時間のみ。休息は経過時間だけで自動加算せず、終了後の自己申告を必須にする。物語は休息記録に応じた創作であり、実際の行動を検知した証拠ではない。

未訪問だけでは空腹・ごきげん・汚れ・健康を悪化させない。休息報酬も未訪問だけでは発生しない。

保存は従来のキーを維持し、内部version4に検証付き移行。version1/2/3のデータと進行中の30分タイマーを引き継ぐ。旧データに存在しない過去の物語は捏造しない。検証モードは別キー。

ホーム画面からの独立表示をmanifestに指定。Safariの通常タブのURLバーを自動的に隠す機能ではない。実機の挙動は別途確認が必要。

## 開発・公開

- `npm run test:unit` — 純粋ロジックのテスト
- `npm run build` — allowlistの10ファイルのみdistへ
- `npm run dev` — ローカルプレビュー
- `npm test` — Chromium/WebKitの実操作テスト
- `npx wrangler deploy` — tamago2 Workerへ公開
- `npm run verify:live` — 公開版情報と9ファイルのSHA-256をローカル成果物と照合

CIはmain更新後に公開ファイル照合と本番操作テストも実行する。コード更新やdry-runだけで公開完了としない。
