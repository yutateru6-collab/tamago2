# tamago2 — 置くほど育つバーチャルペット

スマホから離れる時間を「育成」に変える、デジタルデトックス向けのバーチャルペット実験。

## いまの核

- 最初は卵。短い孵化演出から始まる
- スマホを置く時間が増えるほどフォームが進化する
- 触りすぎる時間が増えるとフォームが退化し、元気・清潔さが落ちる
- 汚れ／うんち、病気、最終的なお別れまで生命ループに含める
- キャラクターは常時ゆっくり歩き、上下動し、瞬きする
- 家具収集よりも「生き物の状態変化」を主役にする
- メイン画面は数字で責めず、「育ってる／弱ってる」のような状態語を中心にする

## Web版の重要な制約

通常のWebページ／Cloudflare Workersだけでは、iPhone全体のスクリーンタイムや他アプリの使用時間を読み取れない。

そのため現在のWeb試作では、次の3つで生命ループを検証する。

1. 「30分スマホを置く」休息タイマー
2. tamago2自体を画面に表示している時間
3. `?dev=1` の検証用シミュレーション

端末全体の使用時間との本番連動は、ネイティブアプリ側の仕組みを別途設計する。

## 操作

端末風UIの3ボタンを使う。

- A: SELECT
- B: OK
- C: BACK

メニューは `STATUS / CLEAN / REST / INFO`。日常的な世話操作を増やしすぎず、「見ない時間」が報酬になる設計を優先する。

## 開発者モード

`/?dev=1`

- 孵化
- +30分休息
- +30分使用
- うんち追加／清掃
- 病気
- お別れ
- リセット

を即時に確認できる。
